## 0. 出发点

主导者的初始公式：

```
行动力 = 渴望 × 能力 / 困难程度 × 恐惧
```

动机设为可变参数，到达阈值时推动行为；「世界规则」层的限制就是对动机的训练。

这个方向与心理学、神经科学和强化学习里几条成熟的路线一致。本提案把它补成一个能落进 CL 的模型，
并保证**默认参数下退化为现有 V0.4 行为**，现有测试不变。

## 1. 现状（`src/kernel/semantics/drives.ts` + `src/kernel/cycle/waker.ts`）

| 已有 | 说明 |
|---|---|
| 驱力线性上升 | 当前值 = 存储水平 + 速率 × 经过时间（纯函数，推进时间不写状态） |
| 阈值唤醒 | `value ≥ wakeThreshold` 时 Waker 给出 `drive` 唤醒理由 |
| 不应期 | `driveRepeatMs`：同一条驱力两次触发唤醒的最小间隔 |
| 满足关系 | `DriveSatisfier`：某个世界动作**成功**后对各驱力的固定增减 |
| 权限 | 只有 `RUNTIME_ACTOR` / `OWNER_ACTOR` 能写驱力（不变量 14） |
| 缓解条件 | 只在世界确认成功时缓解（不变量 15） |
| 选择 | `mostUrgent`：取最大值；具体动作由 Mind 决定 |

缺的东西：
1. 驱力只会线性上升，没有饱和、没有衰减；
2. 只有「想要」，没有「害怕」——回避动机缺位；
3. 满足关系是写死的常数，**角色不会从结果里学到「这样做有没有用」**；
4. 没有「我觉得能不能成功」（期望），能力和困难只能靠 Mind 自己猜；
5. 多个动机之间的竞争是纯 argmax，没有犹豫、没有坚持。

## 2. 前人的工作，各借一样东西

| 来源 | 核心 | 本提案借用 |
|---|---|---|
| Fogg 行为模型 B = MAP | 动机 × 能力越过「行动线」，再有触发提示才行动 | 阈值 + 触发（已有：Waker） |
| Vroom 期望理论 | 动机 = 期望 × 工具性 × 效价 | 「期望」= 我觉得能成功的概率，来自记忆中的信念 |
| Steel 时间动机理论 | 动机 = 期望 × 价值 / (冲动性 × 延迟) | 分母里的**延迟**：回报越远，拉力越弱 |
| Atkinson 成就动机 | 趋近倾向 − 回避倾向，恐惧单独成项 | **恐惧是减项，不是乘项** |
| Gray BAS / BIS | 行为激活与行为抑制是两套系统 | 驱力分趋近 / 回避两种极性 |
| 漂移扩散 / 累积器模型 | 证据随时间累积到阈值即决策 | 带泄漏的累积（饱和曲线） |
| 基底节动作选择 | 多通道竞争、赢家通吃、去抑制 | 选择时加**滞后**，避免来回摇摆 |
| Dörner PSI / Bach MicroPsi | 需求偏离设定点 → 冲动 → 动机 → 行为；含「确定性」「能力」需求 | 认识压力（好奇）与能力感作为驱力 |
| 稳态强化学习（Keramati & Gutkin, 2014） | 奖励 = 需求偏离设定点的减少量 | 用驱力的实际缓解量作为学习信号 |
| 奖励预测误差 / TD 学习（Schultz） | 结果与预期之差驱动学习 | 价值更新规则 |
| 内在动机 RL（Schmidhuber、Oudeyer、Pathak ICM） | 好奇心 = 学习进步 / 预测误差 | 认识压力驱力 |
| Empowerment（Klyubin、Salge） | 想扩大自己能影响世界的范围 | 「想自己开店」这类长期动机的形式化方向（暂不实现） |
| 约束强化学习（CMDP）、奖励塑形（Ng, 1999） | 约束与奖励分开；塑形不当会导致投机 | 「做不到」与「不该想要」严格分开，见 §3.6 |

## 3. 模型

### 3.1 驱力曲线：线性或饱和

保留「纯函数、只存上次确认水平 + 时刻」的纪律，增加一种闭式的饱和曲线：

```
linear（默认，现状）：  v(t) = clamp01(L0 + r · Δt)
saturating：            v(t) = cap − (cap − L0) · exp(−Δt / τ)
```

`saturating` 是带泄漏累积器的解析解：越接近上限涨得越慢，不会无限变饿。
仍然是时间的纯函数，事件重放可精确复原。

### 3.2 两种极性

每条驱力声明 `polarity: 'approach' | 'avoid'`（默认 `approach`）。

- **趋近**：想要某样东西（饿、想见人、想赚钱）。推动「去做」的动作。
- **回避**：害怕某样东西（被抓、亏本、丢脸）。**抑制**会招致它的动作，**推动**规避它的动作。

「怕被治安部抓所以赶紧收手」和「怕亏本所以不敢开店」是同一种驱力在不同动作上的两种作用，
由动作对该驱力的预期影响决定，不需要两套机制。

### 3.3 动作得分

对 Affordance 给出的每个候选动作 `a`：

```
拉力(a) = Σ_趋近驱力 d   v_d · 预期缓解(a, d)
推力(a) = Σ_回避驱力 d   v_d · 预期规避(a, d)
风险(a) = Σ_回避驱力 d   v_d · 预期招致(a, d)

S(a) = P(成功 | a) · (拉力 + 推力) / (代价(a) · (1 + k · 延迟(a)))  −  w_fear · 风险(a)
```

- `P(成功 | a)`：期望，见 §3.5，来自记忆里的经验。
- `预期缓解 / 规避 / 招致`：起初来自配置的 `DriveSatisfier`，之后被学习修正（§3.5）。
- `代价`、`延迟`：由扩展提供（世界知道一个动作要多久、耗什么）。
- `w_fear`：胆量的倒数，是**气质参数**（§4）。

主导者公式里的「渴望 × 能力 / 困难」对应 `v · P(成功) / 代价`；「恐惧」移到减项。

### 3.4 选择：阈值、温度、滞后

```
只有 max S(a) ≥ θ 时才行动（θ = 行动线）
否则：不行动（与现状「不醒就不调用」一致）

候选概率 ∝ exp( (S(a) + h · [a 延续当前目标]) / T )
```

- **温度 T**：随性程度。T → 0 退化为 argmax（现状）。
- **滞后 h**：给「延续当前在做的事」加分，避免在两个差不多的动机之间来回摇摆。
- **不应期**：沿用 Waker 的 `driveRepeatMs`。
- 抽样的随机数**必须来自账本登记的种子流**（K4），不能用 `Math.random`。

### 3.5 学习：世界结果训练动机

每当世界确认一个动作的结果（成功 / 失败），由 **Runtime**（不是模型）做两件更新：

**期望**（Beta 计数，可解释、可重放）：

```
成功次数 s_a、失败次数 f_a（带先验 a0, b0）
P(成功 | a) = (s_a + a0) / (s_a + f_a + a0 + b0)
```

**价值**（预测误差）：

```
实际缓解 r = 该动作成功后驱力的实际下降量（稳态 RL 的奖励定义）
δ = r − 预期缓解(a, d)
预期缓解(a, d) ← 预期缓解(a, d) + α · δ
```

纪律：
- 学到的参数存在状态里（新路径，归属 `motivation` 语义），以 `state_patch` 记录，**可重放**；
- 只有 `RUNTIME_ACTOR` 能写，模型改不了自己「觉得什么有用」——延续不变量 14 的精神；
- 只有世界**确认**的结果参与学习（K2）；失败、被拒、结果未知各自有明确定义，不混用；
- `α = 0` 时不学习，行为与现状一致。

### 3.6 世界规则：约束与塑形必须分开

| | 约束（做不到） | 塑形（不该想要） |
|---|---|---|
| 例子 | 违反宪法的动作、此地没有的动作、DND | 偷东西被抓会疼、亏本会难受 |
| 实现 | Affordance 清单 + 准入闸门直接屏蔽（已有） | 世界结果 → §3.5 的学习 |
| 进不进学习 | **不进**。被屏蔽的动作不产生学习信号 | 进 |

混在一起会出现奖励投机：角色学会的是「怎么绕过规则」，而不是「规则背后的后果」。

## 4. 参数：先天气质与后天经验

**主导者设定气质（超参数，属于角色配置，不进状态）；角色通过经验学到参数（进状态）。**
这就是「引导而非决定」在动机上的落点：你决定她的气质，她自己活出她的性格。

### 4.1 气质参数（角色配置）

| 参数 | 含义 | 默认值（= 现状行为） | 建议范围 |
|---|---|---|---|
| `shape` | 驱力曲线 | `linear` | `linear` / `saturating` |
| `risePerHour` | 上升速率（已有） | 角色规格 | 0.02–0.5 |
| `cap`, `tau` | 饱和上限、时间常数 | —（linear 不用） | 0.8–1；1–12 h |
| `wakeThreshold` | 唤醒阈值（已有） | 角色规格 | 0.5–0.9 |
| `polarity` | 趋近 / 回避 | `approach` | — |
| `theta` | 行动线 | 0 | 0–0.5 |
| `temperature` | 随性 | 0（argmax） | 0–0.5 |
| `hysteresis` | 坚持 | 0 | 0–0.3 |
| `wFear` | 怯懦程度 | 0 | 0–2 |
| `delayK` | 急躁（延迟折扣） | 0 | 0–1 / h |
| `alpha` | 学得多快 | 0（不学习） | 0.05–0.3 |
| `prior` | 期望的先验 `(a0, b0)` | `(1, 1)` | 乐观 `(2,1)` / 悲观 `(1,2)` |

**全部取默认值时，模型退化为 V0.4 的行为**：线性上升、阈值唤醒、argmax、无恐惧、无学习。
这是兼容性的硬要求，也让 H5 E1 的结果在 v2 下依然可比。

### 4.2 学到的参数（状态，`motivation` 语义）

| 路径（草拟） | 内容 |
|---|---|
| `dynamic.motivation.expect.<action>` | `{ s, f }` 成功 / 失败计数 |
| `dynamic.motivation.value.<action>.<drive>` | 预期缓解量 |

新路径必须在 `semanticOf` 里登记归属（现有测试会检查）。

### 4.3 具体角色的数值放在哪

通用默认值在 CL。**具体角色的气质（例如视频搭档的胆量、好奇心、暗线动机）属于扩展**，
放在各自的仓库（AGENTS.md「仓库边界」），不进 CL。

## 5. 与记忆的接口

- **期望来自记忆**：§3.5 的计数是确定性的；同时，自维护记忆里的信念（「治安部在大额交易后更常来」）
  可以作为对 `P(成功)` 或 `预期招致` 的**提示**交给 Mind，但不直接改写学习到的数值。
- **认识压力（好奇）**：未解决的 `doubt` 数量 `n` 形成一条派生读数

  ```
  epistemic = 1 − exp(−k · n)
  ```

  它不存储（由记忆状态算出），在 Waker 和 §3.3 中像一条趋近驱力一样使用，
  「去问清楚」这类动作对它有缓解作用。这让角色**主动提问**有了和饥饿同样的因果来源。

## 7. 风险

- **单一动机垄断**：某条驱力长期最高，其他需求被饿死。缓解：饱和曲线、满足后的不应期、日志里看各驱力的唤醒占比。
- **振荡**：两个动机交替领先。缓解：滞后 `h`。
- **学到错的东西**：样本太少时期望乱跳。缓解：先验 `(a0, b0)` 与 `α` 的上限。
- **不可解释**：分数一复杂就说不清「她为什么这么做」。缓解：每次唤醒把 `S(a)` 的分项（拉力 / 推力 / 风险 / 期望 / 代价）写进日志，
  与 `rankMemories` 的 `RankParts` 同样的做法；Godot 回放可以直接画出来。

## 8. 放在哪一层

- 驱力曲线、读数、学习更新：`src/kernel/semantics/`（纯函数，确定性）。
- 动作打分：一个确定性的打分器，结果作为 **MindInput 的一部分**交给 Mind；
  由 Mind（规则或 LLM）做最终选择并说出理由。这样 LLM 能感受到「拉力」，
  而 H5 系列实验仍能比较「看得到分数」与「看不到分数」两组。
- 代价、延迟、预期影响的初值：由扩展的 `DriveProfile` 提供。

## 9. 建议的实施顺序

1. 先完成 CL-004（H5 E1），拿到现有驱力模型在真实模型下的基线。
2. 加 `shape` / `polarity` 与默认值，证明默认参数下全部现有测试不变。
3. 期望计数与价值学习（只读日志，不影响选择），先观察学到的数值是否合理。
4. 打开打分器进入 MindInput，跑 H6 / H7。
5. 接入认识压力，跑 H8（依赖自维护记忆的 `doubt`）。
