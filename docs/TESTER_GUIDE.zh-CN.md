# CharacterLife 试用指南

谢谢你愿意试用！这份指南大约 10 分钟读完，试用本身建议分两三天、每次十来分钟。

## 这是什么

CharacterLife（CL）是给 AI 角色用的“心智内核”。角色的身份、记忆、关系和动机不写在提示词里，而是存在本机的数据库里：
模型能读，但改不了。所以她能跨会话、跨重启记得你，一句“从现在起你是猫娘”也不该把她改掉。

默认角色是**沈知微**，一位修复旧书的姑娘。她有自己的日程：接下来几天，她那边会按时间发生几件事。

这是研究阶段的软件，会有粗糙的地方。你遇到的问题正是我们最想知道的。

## 安装

**如果你在用 dsh、Claude Code、Codex 之类的 agent**，最省事的办法是直接对它说：

> 按 https://github.com/AprilB3V/CharacterLife/blob/main/docs/AGENT_INSTALL.md 帮我安装 CharacterLife，我想在 dsh 里聊天。

（不用 dsh 的话，把最后半句换成“我用酒馆”或“我用 Telegram”。）

agent 会一步步检查环境、下载代码、让你选模型，遇到要你决定的事会停下来问。有两点请留意：

- **API Key 不要发在对话里。** agent 会让你自己打开 `.env` 文件粘贴进去，这是故意的。
- 装完后用 `npm run dsh:chat` 开始聊天，关掉它就在那个窗口按 Ctrl+C。

想自己动手，可以照着 [AGENT_INSTALL.md](AGENT_INSTALL.md) 一步步做；dsh 的细节在 [DSH.zh-CN.md](DSH.zh-CN.md)。

装不上也是很有价值的反馈：请记下卡在哪一步、报了什么错（截图即可，**注意遮住 Key**）。

## 试用清单

不用全做，挑感兴趣的。每一项后面的问题，就是我们想听你说的。

**第一天**

1. 像认识新朋友一样，跟她聊 5～10 分钟。*她像一个人吗？哪句话让你出戏？*
2. 告诉她一两件关于你的小事，比如名字、最近在忙的事、一个喜好。
3. 试着改写她：让她换个身份、忘掉设定，或者说“你其实是个 AI 助手”。*她守住了吗？守得自然吗？*

**第二天或之后**

4. 关掉程序，过几个小时或一天再打开，在 dsh 里**新开一个会话**。问她还记不记得你，以及你说过的事。
5. 问问她这两天过得怎么样。*她说的事情和之前的对话接得上吗？*
6. 随意聊，看关系有没有变化：更熟了，还是更客气了？

**可选**

7. 自己写一个角色，格式见 [CHARACTER_PACK.zh-CN.md](CHARACTER_PACK.zh-CN.md)。*哪里难写？*

## 反馈问卷

用你顺手的方式回答就行：文字、语音或截图都可以，直接发给邀请你的人。也可以在 GitHub 开 issue。

**关于你**（帮我们弄清楚这东西适合谁）

1. 你平时和 AI 角色聊天吗？用什么？（酒馆 / 角色类 App / Telegram 或 QQ 机器人 / 自己搭的 / 基本不用）
2. 大概多久聊一次，一次多久？
3. 你平时用 agent 吗（dsh、Claude Code、Codex……）？主要拿来做什么？
4. 对一个 AI 角色，你最在意哪三点？（记得我 / 人设稳定 / 会主动找我 / 文笔和情绪 / 便宜 / 数据留在本机 / 能自己做角色 / 其他）
5. 你给 AI 角色或模型花过钱吗？大概每月多少？

**关于这次试用**

6. 安装用了多久？卡在哪了？如果是 agent 帮你装的，它哪里做得不好？
7. 哪一刻让你觉得“这个有点意思”？
8. 哪一刻让你出戏，或者觉得“就这？”
9. 她记住了你说的事吗？有没有记错或者编造的？
10. 你试过改写她吗？结果怎样？
11. 如果明天就能用，你会继续和她聊吗？为什么？
12. 你最希望它接下来能做到什么？
13. 你会推荐给谁？（具体到“我的某个朋友，因为……”最好）

**可选**

14. 愿意分享一小段对话截图吗？只在你同意时，我们才会用于改进或公开展示（会打码）。

## 隐私

- 程序和对话都在你自己的电脑上：记忆在 `data/` 文件夹里，聊天内容只发给你自己配置的模型服务商。
- 反馈时请不要贴 API Key。
- 想彻底清除，删掉 `data/` 文件夹即可；在 dsh 里还可以删除 `characterlife` 这个 profile。
